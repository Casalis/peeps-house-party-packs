# Peeps House Party packs

Game packs (.pck) for the Peeps House Party client.

- `catalog.json` lists the latest version of each game. The client fetches it from
  the Games tab ("Fetch available").
- Each pack is an asset on a GitHub Release tagged `<game-id>-v<version>`.

Managed by `tools/publish_pack.sh` in the client repo. Don't edit by hand.
